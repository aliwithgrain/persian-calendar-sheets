۰۱ / INSTALLATION

نصب در Google Sheets

  1. فایل مقصد را باز کنید.

    در Google Sheets از منوی Extensions → Apps Script وارد محیط ویرایش اسکریپت شوید.

  2. کد اصلی را منتقل کنید.

    محتوای فایل Code.gs بسته را در فایل Code.gs پروژه جایگزین کنید. اگر پروژه از قبل کد دیگری دارد، ابتدا یک نسخه از آن نگه دارید.

  3. دو فایل HTML را اضافه کنید.

    از گزینه + → HTML دو فایل با نام‌های Calendar و Settings بسازید و محتوای فایل‌های هم‌نام بسته را در آن‌ها قرار دهید. اگر فایل‌ها از قبل وجود دارند، محتوایشان را جایگزین کنید.

  4. پروژه را ذخیره کنید.

    تغییرات را ذخیره کنید و سپس صفحه Google Sheets را مجدداً بارگذاری کنید.

  5. نصب را بررسی کنید.

    از منوی Persian Calendar → Open Calendar تقویم را باز کنید. ممکن است گوگل هنگام نخستین اجرای بعضی فرمان‌ها از شما بخواهد مجوزها را بررسی و تأیید کنید.

به‌روزرسانی: برای نصب نسخه جدید، محتوای همین سه فایل اجرایی را جایگزین و شیت را دوباره بارگذاری کنید. فایل GUIDE.html فقط راهنماست و نباید به Apps Script اضافه شود.
۰۲ / USAGE

امکانات و فرمان‌ها

Open Calendar
تقویم شمسی را باز می‌کند تا تاریخ انتخاب‌شده در سلول فعال ثبت شود.
Insert Today
تاریخ شمسی روز جاری را در سلول فعال درج می‌کند.
Convert Selection
تاریخ‌های معتبر سلول‌ها یا محدوده انتخاب‌شده را بدون پنجره تأیید به شمسی تبدیل می‌کند.
Set as Persian Date Column
ستون انتخاب‌شده را برای تبدیل خودکار تاریخ‌های ورودی جدید ثبت می‌کند. محتوای قدیمی ستون با این فرمان تغییر نمی‌کند.
Settings
قالب نمایش، نوع ارقام، شیوه بررسی تاریخ‌های مبهم و ستون‌های فعال را تنظیم می‌کند.

۰۳ / SETTINGS & FORMULAS

تنظیمات و محاسبات

در بخش Settings می‌توانید نمایش عددی یا نوشتاری تاریخ، ارقام فارسی یا لاتین، نحوه تفسیر تاریخ‌های مبهم (DMY/MDY) و تبدیل خودکار ستون‌ها را تنظیم کنید.

توابع قابل استفاده در سلول‌ها

=JALALI_SERIAL(A2)شماره ترتیبی روز برای مقایسه یا مرتب‌سازی
=JALALI_DIFF(A2,B2)محاسبه اختلاف روز بین دو تاریخ
=JALALI_ADD(A2,10)افزودن ده روز به تاریخ شمسی

جداکننده آرگومان‌های فرمول ممکن است بسته به تنظیمات منطقه‌ای Google Sheets ویرگول یا نقطه‌ویرگول باشد.

۰۴ / IMPORTANT NOTES

نکات مهم

  • تاریخ شمسی در سلول‌ها به‌صورت متن ذخیره می‌شود، نه Date بومی Google Sheets.
  • محدوده سال‌های جلالی پشتیبانی‌شده ۱۲۰۰ تا ۱۶۰۰ است. تاریخ‌های دارای ساعت به‌طور خودکار تبدیل نمی‌شوند.
  • هر بار تبدیل گروهی حداکثر ۲۵٬۰۰۰ سلول را بررسی و ۳٬۰۰۰ مقدار را تبدیل می‌کند؛ سقف تبدیل خودکار در هر ویرایش نیز ۳٬۰۰۰ سلول است.
  • برای جلوگیری از تغییر ناخواسته، فرمول‌ها و سلول‌های دارای اعتبارسنجی یا حفاظت‌های مشخص در تبدیل گروهی کنار گذاشته می‌شوند.
  • برنامه قابلیت Backup اختصاصی ندارد و بازگشت تغییرات با Ctrl + Z تضمین نمی‌شود.
پیش از تبدیل گسترده: از مسیر File → Make a copy یک نسخه آزمایشی از شیت تهیه کنید. تاریخچه نسخه‌های Google Sheets نیز از مسیر File → Version history در دسترس است.

رفع اشکال سریع

اگر منوی Persian Calendar نمایش داده نمی‌شود، صفحه شیت را مجدداً بارگذاری کنید. اگر عملیات با خطای مجوز متوقف می‌شود، دسترسی ویرایش فایل و مجوزهای Apps Script را بررسی کنید.
