# Persian Calendar for Google Sheets

**تقویم و مبدل تاریخ جلالی برای Google Sheets**

ابزار **Persian Calendar** مبتنی بر **Google Apps Script** است و امکان انتخاب تاریخ از تقویم شمسی، درج تاریخ روز، تبدیل تاریخ‌های میلادی به جلالی و یکدست‌سازی خودکار ورودی‌های تاریخ در ستون‌های تعیین‌شده را فراهم می‌کند. این ابزار در محیط Google Sheets اجرا می‌شود و برای تبدیل تاریخ به سرویس بیرونی وابسته نیست.

## دریافت و نصب

فایل `Persian-Calendar-v1.0.0-Install.zip` را از بخش **Assets** در آخرین انتشار دریافت کنید. بسته شامل سه فایل اجرایی در پوشه `src/`، راهنمای فارسی `GUIDE.html` و مجوز `LICENSE` است.

فقط محتوای سه فایل داخل `src/` را به پروژه Apps Script مربوط به فایل Google Sheets منتقل کنید. `GUIDE.html` را می‌توانید در مرورگر باز کنید.

## امکانات

پس از نصب و بارگذاری مجدد فایل، منوی **Persian Calendar** به Google Sheets اضافه می‌شود.

| عملکرد | فرمان |
| ---: | ---: |
| تقویم جلالی را در پنل کناری باز می‌کند و تاریخ انتخاب‌شده را در سلول فعال می‌نویسد | **Open Calendar** |
| تاریخ جلالی روز جاری را بر اساس منطقه زمانی فایل درج می‌کند | **Insert Today** |
| تاریخ‌های معتبر را در محدوده انتخاب‌شده به جلالی تبدیل یا از نظر قالب یکدست می‌کند | **Convert Selection** |
| ستون‌های انتخاب‌شده را برای تبدیل خودکار تاریخ‌های جدید ثبت می‌کند و مقادیر قبلی را تغییر نمی‌دهد | **Set as Persian Date Column** |
| قالب تاریخ، نوع ارقام، رفتار تاریخ‌های مبهم و مدیریت ستون‌های ثبت‌شده را کنترل می‌کند | **Settings** |

تقویم دارای میان‌بر دسترسی به تنظیمات است. تبدیل گروهی بدون پنجره تأیید اضافی اجرا می‌شود و فقط مقادیر معتبر و قابل‌شناسایی را تغییر می‌دهد.

## نمونه‌های تبدیل

خروجی‌های زیر با قالب عددی و ارقام فارسی نمایش داده شده‌اند:

| خروجی | ورودی |
| ---: | ---: |
| `۱۴۰۴/۰۳/۰۷` | `Wednesday,28 May 2025` |
| `۱۴۰۳/۰۹/۲۶` | `monday,16 december 2024` |
| `۱۴۰۴/۰۱/۲۵` | `Monday,14 April 2025` |
| `۱۴۰۵/۰۷/۲۶` | `2026/10/18` |
| `۱۴۰۵/۰۷/۲۶` | `1405/7/26` |
| بدون تغییر؛ این تاریخ در حالت پیش‌فرض مبهم است | `03/04/2026` |

نام روز هفته، در صورت وجود، اعتبارسنجی می‌شود. تاریخ‌های نامعتبر یا ناشناخته به‌صورت پیش‌فرض تغییر نمی‌کنند.

## تنظیمات

- **قالب تاریخ:** می‌تواند عددی یا نوشتاری با نام ماه فارسی باشد.
- **ارقام:** می‌توانند فارسی یا لاتین باشند.
- **تاریخ‌های کوتاه مبهم:** در حالت پیش‌فرض تبدیل نمی‌شوند؛ گزینه‌های `DMY` و `MDY` برای تعیین شیوه تفسیر آن‌ها در دسترس هستند.
- **تبدیل خودکار:** می‌توان آن را برای ستون‌های ثبت‌شده فعال یا غیرفعال کرد.

تنظیمات در سطح فایل Spreadsheet مشترک هستند.

## توابع محاسباتی

سه تابع سفارشی برای استفاده در فرمول‌های Google Sheets ارائه شده‌اند:

| کاربرد | تابع |
| ---: | ---: |
| تاریخ جلالی را به شماره روز قابل محاسبه تبدیل می‌کند | `JALALI_SERIAL(dateText)` |
| اختلاف دو تاریخ را بر حسب روز محاسبه می‌کند | `JALALI_DIFF(startDate, endDate)` |
| تعداد روز تعیین‌شده را به تاریخ جلالی اضافه می‌کند یا از آن کم می‌کند | `JALALI_ADD(dateText, days)` |

برای نمونه، فرمول `=JALALI_DIFF("۱۴۰۵/۰۷/۰۱", "۱۴۰۵/۰۷/۱۰")` مقدار `9` را برمی‌گرداند. جداکننده آرگومان‌ها ممکن است با توجه به تنظیمات منطقه‌ای فایل `,` یا `;` باشد.

## رفتار تبدیل و حفاظت از داده‌ها

- تبدیل فقط روی محدوده انتخاب‌شده یا ستون‌هایی اجرا می‌شود که کاربر برای تبدیل خودکار ثبت کرده است.
- تاریخ‌های مبهم، نامعتبر و ناشناخته در تنظیمات پیش‌فرض بدون تغییر باقی می‌مانند.
- فرمول‌ها، چک‌باکس‌ها، سلول‌های دارای اعتبارسنجی داده، سلول‌های ادغام‌شده یا محافظت‌شده و متن‌های غیرتاریخی نباید بازنویسی شوند.
- برنامه پشتیبان‌گیری و Restore اختصاصی ندارد. برای بررسی یا بازیابی نسخه‌های قبلی فایل می‌توان از `File → Version history → See version history` استفاده کرد؛ بااین‌حال، بازیابی یک نسخه قدیمی ممکن است تغییرات دیگر فایل را نیز برگرداند.

## محدودیت‌های مهم

- تاریخ جلالی در سلول‌ها به‌صورت **متن** ذخیره می‌شود، نه مقدار Date بومی Google Sheets. برای محاسبه یا مرتب‌سازی زمانی می‌توان از توابع اختصاصی یا ستون کمکی استفاده کرد.
- موتور تقویم سال‌های جلالی **۱۲۰۰ تا ۱۶۰۰** را پشتیبانی می‌کند و تاریخ‌های دارای ساعت را به‌طور خودکار تبدیل نمی‌کند.
- هر اجرای `Convert Selection` حداکثر **۲۵٬۰۰۰ سلول** را بررسی و **۳٬۰۰۰ مقدار** را تبدیل می‌کند. تبدیل خودکار نیز رویدادهای ویرایش بیش از **۳٬۰۰۰ سلول** را پردازش نمی‌کند و در این حالت می‌توان از فرمان دستی Convert Selection استفاده کرد.
- این ابزار Date Picker داخلی Google Sheets را جایگزین نمی‌کند و به‌عنوان افزونه Google Workspace Marketplace نصب نمی‌شود.
